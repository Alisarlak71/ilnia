# طراحی سایت ایلنیا

منبع اصلی هویت برند فایل [`../../CLAUDE.md`](../../CLAUDE.md) است. این فایل همان هویت را برای وب و Tailwind ترجمه می‌کند. **فایل‌های آمادهٔ برند در [`../brand/`](../brand/README.md) هستند:** نشان روی زمینهٔ تیره و روشن، فاوآیکن، `tokens.css` برای Tailwind، `brand.json` و نمونهٔ کامپوننت `<x-logo />`. لوگو را از نو نکش.

## حس کلی
- **فاخر و آرام:** فضای خالی زیاد، رنگ‌های محدود و خطوط نازک طلایی.
- **صادق:** عکس واقعی، متن ساده و بدون اغراق. از بنرهای شلوغ «تخفیف ویژه!!»، شمارندهٔ معکوس و پاپ‌آپ پرهیز کن.
- **گرم و ایرانی:** نقش‌های هندسی ملایم از گلیم و گبه، فقط به‌عنوان جزئیات.

## رنگ‌ها (Tailwind theme)
```css
@theme {
  --color-ink: #1E1A16;        /* مشکی گرم: پس‌زمینهٔ تیره، متن اصلی */
  --color-gold: #E2B45A;       /* طلایی روشن: روی زمینهٔ تیره */
  --color-gold-deep: #A8731B;  /* طلایی تیره: روی زمینهٔ روشن */
  --color-cream: #F6EFE2;      /* پس‌زمینهٔ روشن اصلی */
  --color-paper: #FBF8F2;      /* کارت‌ها روی کرم */
  --color-muted: #6B6257;      /* متن فرعی */
  --color-line: #E4DAC6;       /* خطوط جداکننده */
}
```
- **پس‌زمینهٔ اصلی سایت کرم است** و **هدر و فوتر تیره (ink)**.
- **دکمهٔ اصلی:** پس‌زمینهٔ ink با متن cream. در حالت hover، لبهٔ طلایی می‌گیرد.
- **دکمهٔ ثانویه:** لبهٔ نازک gold-deep با متن ink.
- **تضاد رنگ:** متن طلایی روشن روی کرم ناخواناست. روی زمینهٔ روشن همیشه از `gold-deep` استفاده کن.

## فونت‌ها
| کاربرد | فونت |
|---|---|
| لوگو و اسم «ایلنیا» | Reem Kufi 600، **فقط برای اسم برند** |
| لاتین ILNIA | Cinzel 600، با فاصلهٔ حروف 0.55em |
| تیترها | Vazirmatn 800 |
| متن | Vazirmatn 400، با line-height حدود 1.9 |

- فونت‌ها را **روی خود سایت میزبانی کن** (در `public/fonts` یا از طریق پکیج npm مثل `vazirmatn`)، نه از Google Fonts. Google Fonts ممکن است از ایران کند یا در دسترس نباشد.
- اعداد را با Vazirmatn فارسی نمایش بده.

## صفحه‌ها (نسخهٔ اول)
1. **صفحهٔ اول:** هدر تیره با لوگو؛ بخش اصلی با شعار «اصلش را می‌فروشیم، نه ادعایش را» و عکس محصول؛ سه ارزش برند (اصالت، صداقت، لوکس)؛ فهرست محصولات؛ بخش داستان («به رسم نیاکان»)؛ فوتر.
2. **فهرست محصولات:** کارت‌ها با عکس، نام، وزن‌ها و «از … تومان».
3. **صفحهٔ محصول:** گالری؛ انتخاب وزن؛ قیمت؛ دکمهٔ افزودن به سبد؛ توضیحات؛ بخش «این عسل از کجا می‌آید» (فیلد `story`)؛ شرایط نگهداری.
4. **سبد خرید**
5. **تسویه‌حساب:** ورود با موبایل، آدرس، روش ارسال، خلاصهٔ سفارش و پرداخت.
6. **نتیجهٔ پرداخت:** حالت‌های موفق و ناموفق.
7. **حساب کاربری:** سفارش‌ها، وضعیت هر سفارش و کد رهگیری.
8. **دربارهٔ ما:** داستان ایلنیا.
9. **تماس، قوانین و شرایط ارسال.**

## قواعد رابط کاربری
- **موبایل‌محور طراحی کن.** بیشتر بازدیدها از اینستاگرام و با گوشی‌اند. روی عرض 375px تست کن.
- **همهٔ متن‌ها راست‌به‌چپ‌اند.** از کلاس‌های منطقی Tailwind استفاده کن (`ms-*`، `me-*`، `ps-*`، `pe-*`، `text-start`)، نه `ml-*` و `mr-*`.
- **قیمت‌ها به شکل `۴۵۰٬۰۰۰ تومان`** نمایش داده می‌شوند، با عدد فارسی و جداکنندهٔ هزارگان.
- **حالت‌های خالی و خطا را طراحی کن:** سبد خالی، محصول ناموجود، پرداخت ناموفق، کد OTP اشتباه.
- **هر عکس متن جایگزین (`alt`) فارسی دارد.**
- **جای خالی عکس:** تا وقتی عکس واقعی نداریم، یک کادر کرم با نشان ایلنیا در مرکز بگذار.
